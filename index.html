Quantum foundations

Build an intuitive understanding before moving into algorithms and quantum machine learning.

⚛️

Qubits

The basic unit of quantum information. A qubit can be in a state described by amplitudes for the basis states |0⟩ and |1⟩.

Quantum state
〰️

Superposition

A quantum state can combine basis states. Measurement produces an outcome probabilistically; it does not let us simply read all possibilities at once.

State preparation
🔗

Entanglement

Multi-qubit correlations that cannot be described as independent states for each qubit. Bell states are a standard example.

Multi-qubit systems
➰

Quantum gates

Operations such as X, Z, H and CNOT transform quantum states. Gates are assembled into circuits.

Circuit building
📐

Amplitudes & phase

Amplitudes can be positive, negative or complex. Probabilities are squared magnitudes, while relative phase affects interference.

Linear algebra
📡

Measurement & noise

Measurement returns classical outcomes. Real hardware is affected by noise, decoherence and imperfect gates.

Hardware reality
Key idea: An amplitude is not a probability. For amplitude α, the probability of its basis outcome is |α|². A negative sign or complex phase can change interference even when the immediate measurement probabilities are unchanged.

Hadamard example

Applying H to |0⟩ creates an equal superposition:

H|0⟩ = (|0⟩ + |1⟩) / √2

Each outcome has probability 1/2 when measured in the computational basis.

Bell pair example

Apply H to qubit 0, then CNOT with qubit 0 as control and qubit 1 as target:

(|00⟩ + |11⟩) / √2

Ideal measurement gives 00 or 11, not 01 or 10.

First quantum circuit

Code lab: superposition & entanglement

Run in a Python notebook after installing Qiskit and Qiskit Aer. These are educational simulator examples.

Example 1 · Hadamard measurement

Prepare |0⟩, apply H, measure 1,000 times. Expect approximately equal 0 and 1 counts on an ideal simulator.

Python · Qiskit
# Install once in a notebook:
# %pip install qiskit qiskit-aer

from qiskit import QuantumCircuit, transpile
from qiskit_aer import AerSimulator

qc = QuantumCircuit(1, 1)
qc.h(0)
qc.measure(0, 0)

simulator = AerSimulator()
compiled = transpile(qc, simulator)
result = simulator.run(compiled, shots=1000).result()

print(result.get_counts())

Example 2 · Bell entanglement

H creates a superposition on qubit 0; CNOT correlates the two qubits. Ideal outcomes are 00 and 11.

Python · Qiskit
from qiskit import QuantumCircuit, transpile
from qiskit_aer import AerSimulator

qc = QuantumCircuit(2, 2)
qc.h(0)
qc.cx(0, 1)
qc.measure([0, 1], [0, 1])

simulator = AerSimulator()
compiled = transpile(qc, simulator)
result = simulator.run(compiled, shots=1000).result()

print(result.get_counts())
# Ideal simulator: mostly '00' and '11'
Qiskit versions evolve. If an install or import fails, check the current IBM Quantum documentation and package compatibility. Real hardware results may differ because of noise.

Quick reference

Quantum glossary

A compact reference for terms that appear throughout the portal.

TermPlain-English meaning
QubitQuantum information unit, represented by a state in a two-dimensional complex vector space.
AmplitudeComplex coefficient associated with a basis state; squared magnitude gives measurement probability.
PhasePart of an amplitude that influences interference and quantum-state relationships.
EntanglementQuantum correlation that cannot be represented as independent states of the parts.
QAOAQuantum Approximate Optimization Algorithm, a hybrid variational optimization method.
VQEVariational Quantum Eigensolver, a hybrid method often used for energy estimation.
QMLQuantum machine learning: methods combining quantum circuits with machine-learning tasks.
DecoherenceLoss of quantum coherence due to interaction with the environment.
Hybrid algorithmA workflow where classical and quantum processors share the computation.
Post-quantum cryptographyCryptography designed to resist attacks from future large-scale quantum computers.
